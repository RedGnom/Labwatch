# Labwatch
1) Участники:
   - Молодых Никита Андреевич — @MolodyhN
   - Хасаншин Арсен Рустамович> — @RedGnom

2) Тема проекта: система мониторинга и управления серверной/домашней
   лабораторией с мобильным приложением и удалёнными алертами.

3) Задачи:
   - Разработка Linux-сервиса (Raspberry Pi / Linux-ПК) на FastAPI,
     который собирает телеметрию с датчиков узла (температура CPU,
     температура корпуса, влажность, ток, обороты вентилятора,
     напряжение) — на старте данные симулируются, архитектура
     предусматривает замену на реальные датчики одной строкой конфига.
   - Реализация порогов и сценариев: авто-включение вентилятора при
     перегреве, уведомление при скачке тока, аварийное логирование,
     «watchdog» для перезагрузки узла.
   - Разработка REST API на FastAPI: приём телеметрии, хранение в
     PostgreSQL, отдача истории, управление реле, авторизация.
   - Создание Android-приложения: дашборд с графиками в реальном
     времени, список узлов, настройка порогов, журнал инцидентов,
     push-уведомления, удалённая перезагрузка.
   - Обеспечение безопасности: JWT-авторизация, шифрование канала
     (HTTPS), валидация данных.

4) Ожидаемый результат к декабрю 2026 года:
   - Работающий прототип Linux-сервиса, обслуживающий не менее 3
     «узлов» с симулированными датчиками.
   - Android-приложение с дашбордом, графиками, алертами и управлением.
   - Задокументированный REST API (OpenAPI/Swagger).
   - Отчёт о тестировании сценариев (перегрев, скачок тока, потеря связи).
   - Публичный git-репозиторий с README, промптами и инструкцией
     по развёртыванию.
